# Melontik marka kiti

Kaynak: Canva marka kiti ("Brand colors" paleti).

## Logo

| Dosya | Açıklama |
| --- | --- |
| `melontik-icon.webp` | İkon (mercan daire, şeffaf zemin) |
| `melontik-icon.jpg` | İkon, JPG (beyaz zemin) |
| `melontik-logo-stacked.webp` | Dikey logo: ikon üstte, koyu kahve yazı |
| `melontik-logo-horizontal.webp` | Yatay logo: mercan ikon, koyu kahve yazı |
| `melontik-logo-horizontal-coral.webp` | Yatay logo: açık pembe ikon, mercan yazı |

## Renkler

| Renk | Kod | Kullanım |
| --- | --- | --- |
| Mercan | `#FF7855` | Ana marka rengi, vurgular |
| Açık pembe | `#FFE4DD` | Logo içi, açık zeminler |
| Koyu kahve | `#26120D` | Koyu zemin, metin |
| Sıcak gri | `#8D7F7C` | İkincil metin |
| Gri | `#A9AAAA` | Nötr |
| Açık mavi | `#56DDFF` | İkincil vurgu |

Görsel ve post tasarımlarında vurgu rengi olarak mercanı kullan.

## Yazı tipi

Montserrat (tüm stiller). Başlıklar kalın (Bold/ExtraBold), gövde ve açıklama metinleri normal ağırlıkta.
